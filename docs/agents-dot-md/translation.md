# Language conventions

> Talk to the user in Simplified Chinese; write everything in the repository in English.

- Conversation: Simplified Chinese by default; English only when the user asks for it.
- Repository content is always English: code, identifiers, comments, UI text, commit messages, README, AGENTS.md, every file under `docs/`, and new memory or checklist entries added later. Don't add Chinese text to committed files, even when the user writes in Chinese.
- UI text: sentence case, active voice, and buttons that say exactly what they do ("Add worktree", not "Submit").
